# Valm Dex

**A Roblox Dex that goes beyond the basics.**

Valm Dex isn't trying to be another basic Explorer with a few extra buttons. Instead of a basic-ass Dex like Dex REContinued or LQ Explorer, this thing goes further with its own decompiler, Fin assistant, advanced search, AI tools, plugin system, and a lot more.

It's built to give you more control over what you're inspecting, how you work with scripts, and what tools you can add.

## Features

### Explorer & Advanced Search
- Search by instance name, class, full path, tags, attributes, and GUI text.
- Combine multiple filters and save them as presets.
- Inspect instances, properties, attributes, and children.
- Insert objects directly from Explorer.
- Switch between different Roblox class icon sets.

### Valm Decompiler
- Native script decompilation.
- Reconstruction for complex control flow and nested functions.
- Additional fallback decompiler support.
- Output for inspecting and analyzing scripts.

### Fin — Dex Helper
Fin is the built-in assistant for Dex. It can answer questions and use MCP tools to inspect your game.

Its tools include instance inspection, property and attribute lookup, script searching, RemoteEvent listing, workspace auditing, plugin information, and decompiler status.

Fin can use your configured AI provider, with local help functions available too.

### AI Beautifier
- Beautify and improve script readability using AI.
- Configure providers, models, and endpoints.
- Adjust generation settings.
- Keep its own configuration while using shared provider credentials where configured.

### Plugin System
- Import and manage community plugins.
- Create custom tabs and interface elements.
- Use the plugin API for buttons, toggles, sliders, dropdowns, notifications, and more.
- Register and call plugin functions.
- Access supported Dex services and theme information.

### Interface
- Multiple built-in themes.
- Theme-aware pickers and dropdowns.
- Different Explorer class icon styles.
- Custom plugin icons.
- Dedicated styling for built-in tools.

## AI & Privacy

**Don't worry, we've got you!**

Your API keys are sensitive. Valm Dex uses configured keys to authenticate requests with your selected AI provider. Keep them private and don't expose them in screenshots, public plugins, or shared scripts.

AI requests are handled by the provider you choose, so check its privacy policy before sending sensitive information.

## More Than the Default Tools

Valm Dex is also built to be extended. The plugin system gives developers room to make their own tools instead of being limited to whatever comes included.

Got an idea for a feature? Build it into Dex.
